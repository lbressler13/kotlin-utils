# Migrating from v1 to v2

## Deprecated Code

Deprecated functions and classes have been deleted.
They should be replaced with the corresponding function/class in another package.
The `MutableSet.popRandom` and `MutableList.popRandom` extension methods have also been replaced with the `MutableCollection.popRandom` extension method.
The changes are as follows:

| Deprecated          | Replacement         | Deprecated Import                                          | New Import                                                     |
|---------------------|---------------------|------------------------------------------------------------|----------------------------------------------------------------|
| `Labelled`          | `Labelled`          | `xyz.lbres.kotlinutils.classes.labelled.Labelled`          | `xyz.lbres.kotlinutils.utils.Labelled`                         |
| `MultiSet`          | `MultiSet`          | `xyz.lbres.kotlinutils.classes.multiset.Multiset`          | `xyz.lbres.kotlinutils.collections.multiset.MultiSet`          |
| `MutableMultiSet`   | `MutableMultiSet`   | `xyz.lbres.kotlinutils.classes.multiset.MutableMultiSet`   | `xyz.lbres.kotlinutils.collections.multiset.MutableMultiSet`   |
| `multiSetOf`        | `multiSetOf`        | `xyz.lbres.kotlinutils.classes.multiset.multiSetOf`        | `xyz.lbres.kotlinutils.collections.multiset.multiSetOf`        |
| `mutableMultiSetOf` | `mutableMultiSetOf` | `xyz.lbres.kotlinutils.classes.multiset.mutableMultiSetOf` | `xyz.lbres.kotlinutils.collections.multiset.mutableMultiSetOf` |
| `emptyMultiSet`     | `emptyMultiSet`     | `xyz.lbres.kotlinutils.classes.multiset.emptyMultiSet`     | `xyz.lbres.kotlinutils.collections.multiset.emptyMultiSet`     |
| `popRandom`         | `popRandom`         | `xyz.lbres.kotlinutils.set.mutableset.popRandom`           | `xyz.lbres.kotlinutils.collection.popRandom`                   |
| `popRandom`         | `popRandom`         | `xyz.lbres.kotlinutils.list.mutablelist.popRandom`         | `xyz.lbres.kotlinutils.collection.popRandom`                   |
| `ternaryIf`         | `simpleIf`          | `xyz.lbres.kotlinutils.general.ternaryif`                  | `xyz.lbres.kotlinutils.utils.simpleIf`                         |


## ext

Any code in a package ending in `.ext` has been moved to its parent package.
For example, the String extension method `isInt` has been moved from
```kotlin
xyz.lbres.kotlinutils.string.ext
```
to
```kotlin
xyz.lbres.kotlinutils.string
```


## general

The `general` package has been renamed to `utils`.

| Previous Package | New Package | Example Usage                          |

## collection

The following packages have been consolidated under the `collection` package:
- `list`
- `map`
- `multiset` (moved from `set.multiset`)
The methods from the `collection.mutable` subpackage have also been consolidated under `collection`.

The following subpackages have been consolidated under the new subpackage `collection.number`:
- `collection.char`
- `collection.int`
- `collection.long`
The `collection.boolean` subpackage has also been renamed to `bool`.
